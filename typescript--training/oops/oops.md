# OOPS IN TYPESCRIPT

## What is Class?
Class is a template or data type that can help to store data, methods and object together in one place.

## What is object?
Object is all about new instance of the class.(new instance meaning new copy of the class)
 
## What is constructor in the class?
constructor is default method created by typescript every time we are going to create new class.that is going to initializa all the properties of the class wherever we are going to create object.

## Access modifiers in the typescript
Access modifiers are set of keywords that we can used to control the access of data and methods stored in the classes.

//1. Public / no-keyword => open access, we can access data and methods everywhere
//2. Protected => we can access the data and methods either within the class or its sub-classes or child class
//3. Private => we can access data and methods within the class only. not outside of the class
